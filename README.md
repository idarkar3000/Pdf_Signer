# Pdf_Signer

Aplicacion de escritorio desarrollada en C# y WPF (.NET 10) para visualizar documentos PDF y estampar firmas manuscritas de forma fluida y precisa.

## Características

* Visor PDF interactivo con zoom, navegacion de paginas y vista adaptable.
* Lienzo interactivo para dibujar firmas con modo borrador por trazos y grosor personalizable.
* Estampado dinamico con soporte para arrastrar, reescalar y posicionar la firma en tiempo real.
* Integracion UX completa con soporte Drag & Drop para abrir archivos PDF.
* Sistema de atajos de teclado y funcionalidad Deshacer / Rehacer (Ctrl+Z y Ctrl+Y) tanto para el dibujo de la firma como para el posicionamiento sobre el PDF.
* Exportacion final vectorizada garantizando la integridad del documento y la transparencia de la firma.

## Tecnologias Utilizadas

* Lenguaje: C# / WPF (.NET 10)
* Renderizado PDF: PdfiumViewer
* Manipulacion y Modificacion PDF: PdfPig

## Requisitos e Instalacion

1. Clonar el repositorio:
   git clone https://github.com/idarkar3000/Pdf_Signer.git

2. Abrir el proyecto en Visual Studio 2022 o posterior.
3. Compilar y ejecutar la solucion.
